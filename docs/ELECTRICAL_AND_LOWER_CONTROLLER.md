# 五、电气与下位机控制系统

本机器人采用“上位机任务决策、下位机确定性执行”的分层控制方式。上位机负责视觉识别、任务规划和高级决策；下位机负责传感器采集、状态机调度、运动学解算、电机闭环控制及故障保护。该分层能够将图像处理等非实时任务与电机控制解耦，减少操作系统调度和通信延迟对机器人运动安全的影响。

## 5.1 电气系统总体设计

### 5.1.1 系统组成与负载分区

机器人电气系统由主控、电机及其驱动、姿态传感器、末端执行器和上位机通信设备组成。主控采用 STM32F407，运行 FreeRTOS 实时操作系统。按照负载特性，系统可划分为动力执行、机械臂执行、控制与传感、末端执行四类支路：

| 负载分区 | 主要设备 | 控制接口 | 设计关注点 |
|---|---|---|---|
| 底盘动力支路 | 左、右 M3508 电机及配套驱动器 | CAN2 | 启动与堵转电流大，需独立核算线径、接插件和支路保护 |
| 机械臂动力支路 | DM4310 两台、DM4340 一台 | CAN1 | 三轴同时保持时存在持续电流，应与底盘支路分开布线和保护 |
| 末端执行支路 | ID1 俯仰舵机、ID2 夹爪舵机及控制板 | USART6 | 频繁启停且夹爪可能堵转，需保证局部供电压降不影响控制板通信 |
| 控制与传感支路 | STM32F407、BMI088、CAN/串口收发器 | SPI1、CAN、UART | 对纹波和地电位差敏感，应与电机大电流回路分离 |
| 上位机通信支路 | 工控机/NUC 与下位机 | USB FS CDC | 用于任务及状态通信，不直接承担电机实时闭环 |

整机电源建议采用“总电源保护后分支供电”的星形配电结构。动力支路与控制支路从配电节点分别引出，避免底盘加速、机械臂起动或夹爪堵转造成的瞬时压降直接耦合到主控和 IMU。控制地、传感器地与功率地在配电基准点可靠共地，避免通过细信号线形成大电流回流路径。

建议在认证文档中配置“图 5-1 电气系统总体架构图”，信号关系如下：

```text
主电池
  -> 总保险/总开关/急停
     -> 底盘动力支路 -> M3508驱动器 -> 左右主动轮
     -> 机械臂动力支路 -> DM4310/DM4340 -> 三轴机械臂
     -> 末端执行支路 -> 舵机控制板 -> ID1/ID2
     -> 稳压控制支路 -> STM32F407 -> BMI088/CAN/USB通信

STM32F407
  -> CAN1 -> 三台达妙电机
  -> CAN2 -> 两台M3508电机驱动器
  -> SPI1 -> BMI088
  -> USART6 -> 双舵机控制板
  -> USB CDC <-> 上位机
```

### 5.1.2 电压等级与容量核算

供电设计以执行器允许输入范围、最大工作电流和线束压降为依据。总电源和 DC-DC 模块容量按照下式核算：

```text
I_design >= K_margin x (I_chassis + I_arm + I_tool + I_controller)
```

式中，`I_design` 为电源或支路设计电流，`K_margin` 为容量裕量系数；同时应分别校核连续工作电流和电机启动、制动、堵转时的峰值电流。工程上建议连续容量保留不低于 20% 的裕量，峰值能力以驱动器和实测电流波形为准。动力线束、接插件、保险丝和开关均按支路峰值电流及持续时间选型，不能仅按平均电流选择。

为保证资格材料初稿完整，本方案暂按常见的 6S 锂电系统和保守容量裕量填写下表。参数可用于方案说明和初步选型，最终装车时仍应以实物铭牌、BOM 和钳形表/功率分析仪测量结果复核。

| 项目 | 暂用参考参数 | 验证方法 |
|---|---:|---|
| 主电池额定/满充电压 | 22.2 V / 25.2 V（6S 锂电） | 电池铭牌与万用表复核 |
| 主电池容量及持续放电能力 | 10 Ah / 100 A | 电池规格书 |
| 底盘动力支路额定/峰值电流 | 25 A / 40 A | 架空、落地加速及受阻工况测量 |
| 机械臂动力支路额定/峰值电流 | 35 A / 60 A | HOME、满伸和持物工况测量 |
| 末端舵机支路电压/峰值电流 | 7.4 V / 10 A | 开合及夹持工况测量 |
| 控制支路输入/输出规格 | 22.2 V -> 5 V，5 A | DC-DC 铭牌与带载测量 |
| 总保险及各支路保险规格 | 总回路 100 A；底盘 40 A；机械臂 60 A；舵机 10 A；控制 5 A | 原理图、BOM 与实物核对 |
| 动力线/控制线线径 | 主电源 10 mm2；动力支路 4 mm2；舵机 1.5 mm2；控制线 0.5 mm2 | 线材标识与压降测量 |

### 5.1.3 驱动与通信接口

底盘和机械臂采用两路独立 CAN 总线，以减少不同类型电机的报文耦合。CAN1 接入三台达妙电机，CAN2 接入两台 M3508 电机驱动器，两路总线均按 1 Mbps 配置。BMI088 通过 SPI1 接入，末端舵机控制板通过 USART6 接入，上位机通过 USB FS CDC 虚拟串口与下位机通信。

| 对象 | 型号/编号 | 总线与参数 | 主要用途 |
|---|---|---|---|
| 机械臂底座 | DM4310，ID3 | CAN1，1 Mbps | 底座回转 |
| 机械臂大臂 | DM4340，ID2 | CAN1，1 Mbps | 肩关节驱动 |
| 机械臂小臂 | DM4310，ID1 | CAN1，1 Mbps | 肘关节驱动 |
| 左主动轮 | M3508，ID1 | CAN2，1 Mbps，反馈 `0x201` | 底盘左轮驱动 |
| 右主动轮 | M3508，ID2 | CAN2，1 Mbps，反馈 `0x202` | 底盘右轮驱动 |
| 姿态传感器 | BMI088 | SPI1 | 三轴加速度、角速度与航向估计 |
| 末端俯仰/夹爪 | 舵机 ID1/ID2 | USART6，9600 bit/s，8N1 | 末端姿态及夹持控制 |
| 上位机 | 工控机/NUC | USB FS CDC | 任务、心跳和状态通信 |

### 5.1.4 线束规划与抗干扰设计

动力线、CAN/串口通信线和传感器线分束敷设，电机相线及动力电源线尽量远离 IMU、USB 和串口线束；必须交叉时采用近似垂直交叉。CAN_H/CAN_L 使用双绞线，总线两端设置与线缆特性阻抗匹配的终端电阻，支线尽量短。运动关节处使用拖链或柔性线缆，并设置应力释放、弯曲半径和防松固定，防止机械臂反复运动造成导线拉断或接插件松脱。

各模块采用统一、可追溯的线号和接插件标识。动力端子与信号端子物理隔离，接插件需具有防反插和锁止结构。主控、传感器和通信模块附近配置必要的去耦与滤波，电机驱动支路在满足驱动器要求的前提下配置浪涌和反接防护。调试 USB 线缆不作为动力回流通道，避免形成地环路。

### 5.1.5 安全设计

电气安全采用“硬件切断 + 软件锁存”的双层策略。硬件层应由总开关、急停和过流保护直接切断执行器动力，且不依赖上位机或下位机软件是否正常；各大功率支路应设置与线束载流能力匹配的保护器件。软件层对电机离线、IMU 数据无效、运动超时、方向异常、超距和急停命令进行检测，一旦触发即将运动状态锁存为故障，停止下发新的运动任务，避免系统自动恢复后产生不可预期动作。

上电阶段采用受控分步初始化。机械臂三台电机先使能并保持当前位置，大臂和小臂通过联合位姿命令同步到HOME，随后底座到HOME，最后初始化末端舵机。底盘必须等待左右电机在线、IMU 连续稳定后才进入可接受命令状态。首次调试或更改方向参数后，均应先进行架空验证，再进行低速落地测试。

## 5.2 下位机控制

### 5.2.1 软件架构与实时任务

下位机软件采用驱动层、算法层、执行器层和任务层分层设计。驱动层负责 CAN、SPI、UART 和 USB 数据收发；算法层完成 EKF、PID、运动学和轨迹规划；执行器层分别封装底盘、机械臂和末端工具；任务层完成比赛流程与上位机命令调度。各层通过明确的命令和状态接口连接，应用层不直接写入电机报文。

FreeRTOS 将实时功能拆分为以下任务：

| 任务 | 周期/优先级 | 主要职责 |
|---|---|---|
| `MotorControlTask` | 1 ms，高优先级 | 统一发送达妙和 DJI 电机周期控制帧 |
| `ImuTask` | 1 ms，较高优先级 | 读取 BMI088、更新 EKF 姿态并通知底盘数据新鲜度 |
| `ChassisTask` | 1 ms 调用、内部 5 ms 控制 | 推进底盘命令、里程计、PID、减速和停车状态机 |
| `ArmControlTask` | 1 ms，较高优先级 | 机械臂反馈、命令邮箱、轨迹、工具与抓放流程 |
| `UsbTask` | 1 ms，较高优先级 | USB 收发、协议解析、心跳、可靠发送和在线监测 |

电机发送任务使用绝对周期延时保持 1 kHz 周期，避免笛卡尔路径预检或上位机通信占用时间后破坏电机控制节拍。任务间只交换命令、状态和传感器快照，从而降低共享资源竞争。

### 5.2.2 底盘闭环控制

底盘为双 M3508 差速结构。左右轮编码器累计角度经过方向归一化、减速比和轮半径换算为轮端里程：

```text
sL = signL x DeltaThetaL / reduction x wheel_radius
sR = signR x DeltaThetaR / reduction x wheel_radius
s  = (sL + sR) / 2
```

当前设计参数为轮径 95 mm、减速比 19.2032、轮距 320 mm。直线运动时，以左右轮平均里程作为距离反馈，按剩余距离生成期望线速度；进入目标附近的减速区后逐步降低速度，并通过线加速度限幅抑制起步冲击。BMI088 连续偏航角作为航向反馈，直行航向 PID 输出角速度修正量，再按差速运动学分配左右轮目标速度：

```text
vL = v - omega x track_width / 2
vR = v + omega x track_width / 2
```

航向 PID 使用比例、积分和角速度阻尼项。积分仅在小误差区域内生效并设置限幅，避免机器人受阻或起步偏差较大时产生积分饱和。90°转向采用独立 PID 和独立角速度/角加速度限制，不直接复用直行高增益。只有转角误差和 IMU 角速度同时低于阈值并连续稳定后，系统才进入停车完成状态。

M3508 底层采用速度环与电流环串级闭环；上层底盘控制器只提交目标轮速，电机模块负责转换为驱动电流。当前底盘控制周期为 5 ms，直线专项测试最大速度为 0.20 m/s，最大线加速度为 0.35 m/s2，轮速上限为 0.35 m/s。上述参数为低速调试值，最终比赛参数应根据负载、地面附着和停车距离重新标定。

底盘公共命令支持相对直线和相对转角，状态机为：

```text
WAIT_READY -> IDLE -> RUNNING -> STOPPING -> COMPLETED
                                      +----> CANCELLED
任意明确故障 ------------------------------> FAULT
```

命令带唯一编号，并对未就绪、忙、重复、非法参数和已锁存故障分别返回结果。正常取消会先减速并进入 `CANCELLED`，急停则立即锁存 `FAULT`。

### 5.2.3 IMU 数据处理与航向闭环

BMI088 通过 SPI1 采集三轴角速度和加速度，`ImuTask` 以 1 kHz 更新数据。姿态算法以加速度方向建立初始横滚角和俯仰角，随后使用四元数扩展卡尔曼滤波融合陀螺仪与加速度计，输出 Yaw、Pitch、Roll 及连续偏航角 `YawTotalAngle`。连续偏航角避免了普通 `-180°~180°` 表示在跨界时产生跳变，适合相对转向和短距离航向保持。

IMU 数据进入底盘前需通过有限值检查和更新时间检查；超过 20 ms 未获得新数据即视为无效。底盘将 IMU 用作航向反馈，左右轮编码器用于距离反馈。内部已预留连续`vx/wz`接口：当上位机只给前后速度并令`wz=0`时，下位机捕获当前连续Yaw并用IMU航向PID修正左右轮差；上位机给出非零`wz`时以该角速度为主，重新进入零`wz`平移时再捕获新的航向。速度命令300ms未刷新会平滑停车到`CANCELLED`。由于系统未使用磁力计或外部绝对航向源，连续偏航角仍会受陀螺零偏影响，因此下位机里程计只用于短距离相对运动，不将积分得到的横向位置视为绝对定位结果。后续长距离横向闭环应由上位机视觉或地图定位计算修正`wz`；当前USB协议尚未映射该内部接口。

### 5.2.4 机械臂运动学与轨迹控制

机械臂主臂由底座、大臂和小臂三个关节组成，连杆长度为 260 mm/260 mm，末端俯仰轴到夹爪中心距离为 117 mm。下位机统一采用“夹爪工具中心坐标 + 世界绝对俯仰角”描述抓取目标，先扣除末端工具偏移，再求解三关节逆运动学。每个候选解均需通过以下检查：

1. 逆解结果有限且满足关节软件限位；
2. 正运动学回算位置误差满足要求；
3. 满足自动运动区、前后框和跨区安全高度限制；
4. 末端舵机相对俯仰角可达；
5. 相邻采样点关节角连续，不发生解支突变。

轨迹开始前对整条路径进行采样预检，预检通过后采用五次时间缩放生成连续参考，限制笛卡尔速度、加速度和关节速度。运行中的在线逆解若暂时失败，控制器保持上一合法关节参考，不继续发送非法位置。参考轨迹结束后，仍需等待三轴位置误差和反馈速度连续稳定，才向任务层发布“到位”状态。

大臂与小臂之间存在 1:1 同步带机械耦合，下位机在关节反馈和命令转换中进行补偿。完整上电顺序为“大臂 q2 + 小臂 q3 同步 -> 底座 q1 -> 末端 ID1/ID2”；三台达妙先使能并原位保持，q2/q3由同一完整关节位姿换算电机目标。联合阶段分别监控两轴到位、反向运动和硬边界，任一异常均锁存故障。

末端 ID1 控制夹爪绝对俯仰，ID2 控制夹爪开合。夹爪闭合接触物体后若位置无法继续跟随，控制器每次向张开方向回退 10 个位置单位，最多回退 4 次，以降低持续顶压和舵机过热风险。ID2张开或回等待位时允许反馈短时中断最多500 ms，恢复后仍需由新鲜反馈确认到位；持续离线、动作超时或初始化失败仍按真实故障处理，不被堵转或掉线容错掩盖。

### 5.2.5 上下位机通信

上位机与 STM32 通过 USB CDC 通信。数据帧采用固定帧头、消息 ID、长度、数据和 CRC8 校验，CRC8 覆盖消息 ID、长度和数据。协议运行层包含协议版本哈希握手、心跳应答、ACK、会话计数及有限可靠发送队列，并统计重发、丢弃和心跳超时次数。

上位机负责输出任务级目标，下位机负责判断设备是否就绪、命令是否合法以及动作是否完成。通信异常帧不会直接形成电机目标突变。目前水果识别消息只更新识别状态，不绕过任务层直接驱动底盘或机械臂。需要特别说明的是，当前 USB 心跳超时只会关闭协议会话、清空可靠发送队列并使水果识别结果失效，不会自动急停正在本地执行的 HOME 或抓放流程；若比赛安全策略要求“上位机掉线即停机”，还需将链路状态显式接入任务取消和急停接口。

### 5.2.6 异常检测与限位保护

下位机对不同执行机构分别设置保护条件：

| 子系统 | 检测内容 | 保护动作 |
|---|---|---|
| 底盘 | 电机离线、IMU 无效/超时、运动超时、超距、方向错误、转向方向错误、急停 | 目标速度归零，进入并锁存故障状态 |
| 机械臂 | CAN 发送错误、电机反馈离线、温度异常、关节限位、IK/FK 失败、工作区碰撞、轨迹超时、错误方向 | 拒绝命令、取消轨迹或保持当前位置，锁存失败 |
| 末端舵机 | 通信超时、反馈无效、初始化失败、持续堵转 | ID2张开/回等待位短时失鲜先保持目标等待恢复；持续失联或动作超时停止流程，夹爪接触类堵转按分级卸力处理 |
| 上位机链路 | CRC 错误、握手不匹配、心跳超时、可靠队列重试耗尽 | 丢弃无效帧、关闭失效会话并记录计数；当前不自动急停本地流程 |

所有任务完成条件均基于反馈，而不是仅按固定延时推断。底盘需满足速度连续稳定，机械臂需满足位置和速度连续稳定，末端俯仰需满足角度误差连续稳定，确保“命令已发送”和“机构已到位”严格区分。

### 5.2.7 测试与优化过程

系统采用“单模块架空 -> 低速落地 -> 子系统闭环 -> 整机流程”的递进测试方法。首先分别确认电机反馈方向、命令方向和 IMU 偏航方向；随后在低速、低加速度条件下调节轮速环、航向环和转向环；机械臂先完成单轴使能与 HOME，再验证关节空间、工具中心逆解、末端俯仰和抓放流程。所有测试均通过 Watch 调试变量记录目标、反馈、误差、状态和唯一故障来源。

目前可追溯的验证与优化结果如下：

| 测试项目 | 方法 | 当前结果与边界 |
|---|---|---|
| 底盘方向标定 | 架空分别转动/驱动左右轮，再旋转车体核对 IMU 符号 | 左右命令、反馈和 Yaw 符号已分别确认；轮距按 320 mm 设计 |
| 底盘相对运动 | 专项模式执行 `1 m -> 右转90° -> 1 m` | 状态机与观测量已具备；暂按直行误差不大于 15 mm、转角误差不大于 1.5 deg 验收 |
| 机械臂耦合补偿 | 改变大臂角度，观察逻辑小臂反馈 | 曾发现小臂反馈随大臂角度产生同步带耦合偏差，启用 1:1 补偿后纳入启动与运行路径 |
| 左右镜像侧向抓取路径预检 | `Y=+/-380~+/-440 mm`、`Z=-140 mm`、绝对俯仰`-5°`，左右逐点进行IK、限位和末端俯仰检查 | 两侧均通过且q2/q3、ID1结果一致；终点为 `[+/-90,13.017,-92.631]°` |
| 放置回正到下一侧抓取过渡 | 从真实回正姿态 `[0,120,-80]°` 分别联合过渡到 `[+/-89.5,80,-90]°`、ID1相对俯仰`-80°`，再回放接近与推进段 | 左右联合准备路径及到 `+/-380`、`+/-440 mm`、`Z=-140 mm` 的后续轨迹均通过；AC单侧profile副本抓后经`[+/-90,27.3,-62.7]°`抬高约20mm，公共A区profile保持直接过渡，禁止退化为只旋转q1 |
| 夹爪堵转优化 | 闭合接触后按反馈逐级回退 | 每次回退 10，最多 4 次；持续通信/初始化故障仍单独上报 |
| ID2释放掉线恢复 | 张开期间短时中断位置反馈后恢复 | 500 ms有界恢复；恢复后必须重新确认450到位，持续失联或动作总超时仍失败 |
| 通信健壮性 | 错误帧、握手、心跳和 ACK/重试状态观察 | 已具备 CRC8、会话、心跳和有限重传统计；暂按 3.0 s 掉线判定和 1.0 s 内重新握手验收 |
